# Focus Timer 

A simple, distraction-free focus timer built with Kotlin and Jetpack Compose.

Designed for productivity and minimalism.

# Developing
## Requirements
- An Android device that runs version 6.0 *'Marshmallow'* `(API 23)` or above.
    - or the Android Emulator inside Studio can be used
- Android Studio Giraffe (or higher)
- About 5-15GB of space to install the Gradle dependencies and modules.
---


## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/dmx3377/focus-timer.git
```
2. Open in Android Studio
3. Let Gradle sync
4. Run on an emulator or physical device
